Project history

What we did, in order

1. Baseline reproduction

Rebuilt AutoFish's MobileNetV2 regressor; matched the paper to within 0.013 cm (non-occluded).

2. Vision foundation model tests

Compared CLIP and DINOv2 (frozen, last-block, full fine-tune) under identical data/split/metrics.

3. Patch-token DINOv2

Controlled 3-seed study: patch-pooled DINOv2 (1.261±0.054) reliably beats CLS-token DINOv2 (1.843±0.023).

4. EfficientNet-B0

New supervised-CNN challenger: 0.781 cm, only 0.010 cm behind the baseline.

5. Species classification

Same encoders, new task: all models 95–99.6% accuracy.

Next: stronger-recipe search (ongoing)

Cosine LR + weight decay + tuned LR for EfficientNet-B0/ConvNeXt — testing whether a single model can beat the baseline outright.

Code-level ground truth

How it actually works, in code

The exact code behind masking, cropping, the CNN and Transformer forward passes, and how the whole repository is wired together — nothing paraphrased.

1. Building the black mask from the stored polygon

The dataset stores each fish's outline as a polygon. We rasterize it into a black-and-white stencil: black background (0), white fish silhouette (255).

def mask_from_polygons(segmentation, size):
    mask = Image.new("L", size, 0)              # start fully black
    draw = ImageDraw.Draw(mask)
    for polygon in json.loads(segmentation):
        points = list(zip(polygon[0::2], polygon[1::2]))
        draw.polygon(points, fill=255)           # 255 = "this pixel is the fish"
    return mask

2. Applying the mask (this is the actual masking step)

masked = Image.new("RGB", img.size, (0, 0, 0))   # solid black canvas
masked.paste(img, mask=mask)                      # copy real pixels ONLY where mask==255

Image.paste(..., mask=...) copies the real photo through wherever the mask is white, and leaves black everywhere else — this is why overlapping fish disappear from the crop; only the target fish's own polygon is white.

3. Square crop, centred on the fish (never distort the length signal)

ys, xs = np.where(mask > 0)
x0, x1 = xs.min(), xs.max()
y0, y1 = ys.min(), ys.max()
side = max(x1 - x0 + 1, y1 - y0 + 1)     # SQUARE side, from the longer dimension
cx, cy = (x0+x1)/2, (y0+y1)/2            # centre of the fish
x0 = round(cx - side/2); y0 = round(cy - side/2)

Using the longer dimension for both width and height guarantees a square window — a non-square crop, later force-resized to 224×224, would stretch the fish and corrupt the very length we're trying to measure. Then resize to the network's input size:

crop = crop.resize((224, 224), Image.Resampling.BILINEAR)
crop.save(f"crops/{annotation_id:06d}.png")   # cached once, reused by every experiment

4. Inside a CNN encoder (MobileNetV2)

self.features = models.mobilenet_v2(weights=IMAGENET1K_V1)   # pretrained backbone
...
def forward(self, batch):
    image, bbox = batch
    features = self.features(image)             # conv layers -> pooled feature vector
    features = torch.cat([features, bbox], dim=1)  # + 4 bbox numbers
    return self.classifier(features)             # small MLP -> length (cm)

Mechanically: MobileNetV2 is a stack of inverted residual blocks — each expands channels with a 1×1 convolution, applies a cheap per-channel 3×3 depthwise convolution, then projects back down. Stacking many of these shrinks spatial resolution while growing feature depth, ending in one pooled vector — the encoder's summary of the whole image.

5. Inside a Vision Transformer (DINOv2) — CLS token vs. patch tokens, in code

def _features(self, image):
    features = self.encoder.forward_features(image)   # dict of token outputs
    if self.use_patch_tokens:
        return features["x_norm_patchtokens"].mean(dim=1)   # average ALL patch vectors
    return features["x_norm_clstoken"]                      # OR: the single [CLS] vector

The image is sliced into a grid of 14×14-pixel patches; each becomes a token; a learned [CLS] token is prepended; every token attends to every other token via self-attention in each block (global receptive field — unlike a CNN's local one). x_norm_clstoken is one global summary; x_norm_patchtokens is the full spatial grid, still carrying per-location information. Averaging the patch grid keeps that spatial signal — this exact code change is what produced the 1.843→1.261 cm improvement.

6. The training loop, in real code

for epoch in range(1, epochs + 1):
    model.train()
    for batch in train_loader:
        x, target, _ = move_batch(batch, device)
        optimizer.zero_grad(set_to_none=True)
        pred = model(x)                    # forward pass
        loss = criterion(pred, target)     # L1: mean(|pred - target|)
        loss.backward()                    # backpropagation
        optimizer.step()                   # Adam updates every trainable weight
    val_metrics = evaluate(model, val_loader)
    if val_metrics["mae_cm"] < best_val:
        torch.save(model.state_dict(), "best.pt")   # keep ONLY if validation improved

The test set is touched only once, by a separate evaluate.py run on the saved best.pt — it never influences which checkpoint gets chosen.

7. Repository structure and the exact experiment sequence

data/processed/{index.csv, splits.json, crops/*.png}
src/autofish_vfm/{data.py, models.py, train_baseline.py, evaluate.py, metrics.py}
configs/<experiment>.json      # one file per experiment, every hyperparameter
runs/<experiment>/            # OUTPUT: config, history, best.pt, test_metrics.json, predictions.csv
results/{error_analysis, qualitative, figures}/   # built ONLY from saved runs/ files
poster/  docs/                 # final deliverables
  1. build_autofish_index.py: raw annotations → index.csv (+ leakage audit)
  2. make_crops.py: index.csv → every masked crop PNG (steps 1–3 above)
  3. train_baseline.py --config configs/<name>.json: trains, writes runs/<name>/best.pt
  4. evaluate.py --checkpoint best.pt: one-time test scoring → test_metrics.json
  5. error_analysis.py / make_result_charts.py: read saved runs/ files only — no retraining

This sequence is why the project could follow a strict no-repeat rule: every chart, table, and document here is generated from files already saved in runs/ and results/, never by re-running training.
