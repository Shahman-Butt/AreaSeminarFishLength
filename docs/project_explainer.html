The problem

Fish length, measured from a photo

Fisheries science needs fish lengths to judge stock health and legal catch size. Today it is done by hand — slow and invasive. The goal: a camera that measures every fish automatically. We predict one continuous number (length in cm), so this is a regression task.

CLS token vs patch tokens — our key experiment

A vision transformer can describe an image two ways: one global summary vector (the CLS token), or a grid of local vectors, one per image patch (the patch tokens). Toggle below to see the difference.

One global vector for the whole fish

A grid of local vectors → averaged ("patch stacking / pooling")

CLS token

A single summary optimised for "what is this?" — great for recognising the fish, but it discards fine spatial detail. For precise length it underperforms.

Result (3 seeds, identical settings): mean-pooling the patch tokens beats the CLS token 1.261 ± 0.054 cm vs 1.843 ± 0.023 cm — a reliable 0.58 cm gain with non-overlapping ranges. Patch tokens keep the spatial/size detail that length regression needs.
Results

Length estimation — model comparison

Lower is better (full-test MAE, cm). The small purpose-trained CNN still wins; patch-token DINOv2 is the best foundation-model configuration.

Second task

Species classification

We also tested identifying the species. Here all models are strong (95–99.6%). DINOv2 — last for length — jumps near the top, evidence that foundation features suit "what is this?" better than "how big is it?".
